## Brand & Style

The design system evolves the tactile, grounded agricultural foundation into a pristine, Cupertino-inspired Liquid Glass aesthetic. It marries the vitality of organic botanical intelligence with ultra-refined optical craftsmanship. The aesthetic merges precision glassmorphism with dynamic, fluid mesh gradients that evoke living foliage, morning dew, and sunlight diffusing through a lush canopy.

The visual style is characterized by:
- **Liquid Glass Surfaces:** Multi-layered translucent panels featuring deep optical diffusion (`backdrop-filter: blur(24px) saturate(180%)`), casting ambient green-tinted refractions.
- **Specular Precision:** Crisp 1px highlights with asymmetric edge lighting, simulating polished glass catching natural daylight.
- **Luminous Flora Gradients:** Dynamic mesh underlays blending deep emerald, forest depths, luminous lime aurora, and delicate chartreuse glows over a warm pearl canvas.
- **Micro-tactile Feedback:** Liquid spring physics, gentle compression on press, and seamless floating elevation.

## Colors

The color system synthesizes deep botanical chlorophyll with radiant refraction. Rather than flat fills, color functions through luminous translucency and structural refraction.

- **Primary (`#003320` - Deepest Obsidian Forest):** Grounding anchors, critical calls to action, prominent navigation labels, and dominant typography on glass cards.
- **Secondary (`#196C3E` - Luminous Chlorophyll):** Vibrant active states, interactive controls, and affirmative agronomic health indicators.
- **Tertiary (`#00475A` - Deep Cyan Hydrology):** Atmospheric metrics, hyper-localized precipitation readouts, and automated irrigation telemetry.
- **Neutral Pearl Canvas (`#FBF9F3`):** The foundational substrate beneath the liquid mesh gradients, preventing optical glare while maintaining an organic, warm paper cast.
- **Liquid Aurora Underlay:** Dynamic mesh gradients formed by blending `#002113`, `#196C3E`, `#A1F1B7`, and `#D4F789` at varying opacities beneath frosted surfaces to produce continuous liquid depth.
- **Glass Specular Token:** Dual-tone white light refractions (`rgba(255, 255, 255, 0.55)` top-left, tapering to `rgba(255, 255, 255, 0.15)` bottom-right) that define physical glass edges.

## Typography

Plus Jakarta Sans delivers geometric precision balanced by gentle humanist curves. Type elements sitting on translucent glass surfaces require strict optical contrast adherence.

- **Legibility on Glass:** Typography placed over translucent layers must use `#003320` or `#1B1C18`. Text on translucent panels should never drop below a 4.5:1 contrast ratio against the blurred mesh background beneath it.
- **Optical Weight Balancing:** Light text weights (`< 400`) are excluded to avoid edge degradation caused by backdrop diffusion filters.
- **Tabular Alignment:** Financial yields, crop counts, and sensor values utilize tabular figures (`font-variant-numeric: tabular-nums`) to ensure strict columnar stability.

## Layout & Spacing

The layout is constructed on a fluid responsive grid designed to maintain expansive negative space around glass containers, allowing the botanical mesh underlay to breathe.

- **Canvas Mesh Foundation:** The base layer contains fixed fluid gradient mesh nodes that sit pinned behind scrolling glass cards.
- **Desktop (1024px+):** 12-column grid with a maximum content boundary of `1320px`, `48px` outer margins, and `24px` gutters. High-level planning dashboards use 2-to-3 pane glass floating splits.
- **Tablet (768px - 1023px):** 6-column grid, `24px` outer margins, `20px` gutters. Analytics panels and camera diagnostics collapse into unified frosted containers.
- **Mobile (< 768px):** 4-column grid, `16px` outer margins, `16px` gutters. Heavy glass floating cards span full width, with sticky navigation docks floating 16px above the viewport bottom.

## Elevation & Depth

Elevation is rendered through physical refraction, surface diffusion, and specular light dynamics rather than dark drop shadows.

- **Substrate (Elevation 0):** Crisp pearl base (`#FBF9F3`) overlayed with organic radial and conic mesh blobs (`#003320`, `#196C3E`, `#A1F1B7`, and `#D4F789`) with heavy gaussian blurs (`60px` to `120px`).
- **Liquid Glass Panel (Elevation 1):** 
  - Surface: `background: rgba(255, 255, 255, 0.72);`
  - Blur: `backdrop-filter: blur(24px) saturate(180%); -webkit-backdrop-filter: blur(24px) saturate(180%);`
  - Border: `1px solid rgba(255, 255, 255, 0.45);`
  - Specular Glow: `box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.7), 0 8px 32px -4px rgba(0, 51, 32, 0.06);`
- **Floating Controls & Hover States (Elevation 2):**
  - Surface: `background: rgba(255, 255, 255, 0.85);`
  - Shadow: `box-shadow: inset 0 1px 2px 0 rgba(255, 255, 255, 0.9), 0 16px 36px -6px rgba(0, 51, 32, 0.10);`
  - Transform: translates `-1.5px` on the Y-axis with smooth bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Overlays, Sheets & Modals (Elevation 3):**
  - Ambient backdrop: `background: rgba(0, 33, 19, 0.3); backdrop-filter: blur(16px);`
  - Dialog Glass: `background: rgba(255, 255, 255, 0.88); backdrop-filter: blur(32px) saturate(200%); box-shadow: inset 0 1px 2px rgba(255, 255, 255, 0.8), 0 32px 64px -12px rgba(0, 33, 19, 0.22);`

## Shapes

The design system employs continuous curvature (squircle geometry) to emulate natural, hydro-formed liquid shapes.

- **Standard Elements (Buttons, Inputs, Selectors):** Standard radius of `16px` (`rounded-lg`), creating an ergonomic, pebble-like feel.
- **Glass Cards and Viewports:** Scaled between `20px` and `24px` (`rounded-xl`), providing soft framing for botanical telemetry data.
- **Pills and Floating Dock Trackers:** Set to `9999px` (`rounded-full`) for high-level status alerts, micro chips, and bottom persistent action bars.
- **Curvature Hierarchy:** Child elements nested inside cards always sit at least `6px` smaller in radius than their parent containers to ensure optical concentricity.

## Components

### Buttons
- **Primary Liquid Button:** Deep translucent emerald background (`background: linear-gradient(135deg, #164A34 0%, #003320 100%)`), text in `#FFFFFF`, framed with `1px solid rgba(255, 255, 255, 0.25)`. Inner top highlight `inset 0 1px 1px rgba(255, 255, 255, 0.4)`. Drops an ambient shadow (`0 8px 20px -4px rgba(0, 51, 32, 0.3)`).
- **Glass Secondary Button:** Semi-transparent white (`rgba(255, 255, 255, 0.6)`), text `#003320`, `1px solid rgba(255, 255, 255, 0.6)`. Blurs underlying content with `backdrop-filter: blur(12px)`.
- **Ghost Action:** Clear surface, bold label text in `#196C3E`, transitions on hover to `rgba(255, 255, 255, 0.4)`.

### Cards & Panels
- Constructed using the Liquid Glass specification: `rgba(255, 255, 255, 0.72)` fill with `backdrop-filter: blur(24px) saturate(180%)`.
- Surfaced with a dual highlight: an outer `1px solid rgba(255, 255, 255, 0.45)` border paired with an inner specular ring `inset 0 1px 0 0 rgba(255, 255, 255, 0.65)`.
- Metric displays feature translucent tinted circular icons with inset glows matching the metric type (e.g., lime aurora for soil nitrogen, cyan for moisture).

### Chips & Badges

  - **Optimal Growth:** `background: rgba(161, 241, 183, 0.3); border: 1px solid rgba(161, 241, 183, 0.6); color: #003320;`

  - **Advisory Flag:** `background: rgba(255, 218, 214, 0.4); border: 1px solid rgba(186, 26, 26, 0.3); color: #93000A;`

### Form Inputs & Fields
- Translucent white trough (`background: rgba(255, 255, 255, 0.55); backdrop-filter: blur(16px)`).
- Border: `1px solid rgba(255, 255, 255, 0.5)`. Inner shadow: `inset 0 1px 3px rgba(0, 51, 32, 0.04)`.
- Focus State: Transitions to `background: rgba(255, 255, 255, 0.85)` with a glowing ring (`0 0 0 3px rgba(25, 108, 62, 0.25); border-color: #196C3E`).

### Checkboxes & Radio Controls

- Active state transitions smoothly to `#003320` with a pure white checkmark and an inner specular top-ring highlight.

### Specialized Cupertino Agronomic Components
